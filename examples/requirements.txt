# ============================================================================
# 离线 / 内网环境 Python —— 统一 requirements.txt
# 配套完整清单与说明：docs/packages.md
#
# 规则：
#   - 统一一份文件，同时用于 Python 3.12（全量主力）和 Python 3.14（子集）两棵树
#   - 除 pyinstaller<6（Win7 目标机硬性要求）外一律不锁版本，装最新版
#   - 3.14 树上没有 cp314 wheel 的包逐条尝试、失败自动跳过并记录
#   - torch/torchvision/torchaudio 不在本文件，见 requirements-torch-cpu.txt
#     （PyPI 的 torch 会拉数 GB 的 CUDA 依赖，必须走 PyTorch CPU 专用源）
#   - pythonocc-core 不在本文件（PyPI 无 wheel），走 conda-forge 环境复制方案
#   - opencv 只装 opencv-contrib-python（它是 opencv-python 的超集，二者同装会文件冲突）
#
# 安装命令（在联网/开发机执行，先按 docs/playbook.md 配好目录内 pip 隔离）：
#   3.12 树：uv pip install --python <目标树>\python.exe -r requirements.txt
#   3.14 树：逐条循环安装，失败跳过
# ============================================================================
